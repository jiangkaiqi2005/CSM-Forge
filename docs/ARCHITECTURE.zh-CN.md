# CSM-Forge 架构入口

当前规范是 [完整技术总纲](TECHNICAL-SPEC.zh-CN.md)，设计版本 2.0-design。它描述目标体系与改造点，不把新增功能声明为已实现。原 M0 架构按原始 blob 保存在 [历史记录](history/ARCHITECTURE-M0.zh-CN.md)。

## 已确定的技术方向

Host 单写者，Client 提交意图并应用绝对结果；主机玩家操作与自然模拟变化进入同一权威结果流。自有复制状态机要求可重复，不依赖整套 CS1 在各客户端独立确定性运行。实体身份、游戏投影、内容与检查点都有明确版本。

多人运行中加入采用每个成员独立 JoinContext、共享不可变快照、有限日志租约与固定历史 H/A 屏障。快照生成可按游戏能力单工作者执行；不同玩家的传输、加载、追赶和激活不得被全局 isJoining 串行化。慢端或取消只影响自身，Host 不等它完成后才继续游玩。

鲁棒性以最小可信范围隔离：单客户端损坏独立恢复；Host 世界污染才停房。网络连接、加载进展、模拟推进和副本落后分别判断，资源和重试均有界。原生崩溃仍须检查点恢复，不能被 try/catch 保证不发生。

## 当前实现边界

当前生产代码仍是 M0 参考域内核、v1 codec、策略类与未实机验证的 ICities 探针。`CompleteJoin` 等实际入口尚未按 v2 修改；正式网络/模拟/保存/UI 还未接通。新文档和文档检查通过不能被描述为玩家已经可以并行进入。
